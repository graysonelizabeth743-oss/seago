Put your logo here.

  /public/logo.png        (default path, set in src/config/site.js → site.logo.src)
  /public/logo-light.png  (optional: light version for dark backgrounds → site.logo.srcDark)

Recommended: a horizontal logo, transparent background, about 150×40 (2× for sharpness is fine).
SVG works too: change the extension in src/config/site.js.
Until the file exists, a built-in wordmark is shown automatically.
